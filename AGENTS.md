# Cosmograph agent contract

EXO owns portfolio intake, priority, dependencies, release records, and delivery status. Entire is
the primary source forge and the required implementation/session provenance system. GitHub remains
a compatibility and migration mirror. Linear is retired from the active workflow: do not require a
Linear issue, login, Diff, project update, or status transition. Existing issue identifiers and the
temporary customer-feedback adapter are migration evidence only, not execution authority.

Use a short-lived remote canary branch, preserve the initiating prompt in coherent commits, and
record exact validation and delivery evidence. Validated changes integrate into `staging` and are
reviewed at `https://staging.exo.now/cosmograph`; production remains an explicit approval gate.
